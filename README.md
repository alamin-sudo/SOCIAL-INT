# Social interaction and the circulation of residential land use rights in rural Malaysia

This repository is the replication package for *Social Interaction, Property Rights and the Circulation of Residential Land Use Rights: A Multiple Case Survey of Seven Rural Tenure Settings in Malaysia*. It contains:

- **Data:** the verified household data (369 households, 42 kampungs, seven cases; fieldwork January–August 2023) and approximate kampung centroids.
- **Code:** one documented analysis script (estimates, tables, Figures 3–5) and two figure scripts (Figure 1, conceptual framework; Figure 2, study location map).
- **Outputs:** every estimate, results table and figure reported in the paper (Figures 1–5).
- **Licence:** MIT for the code (`LICENSE`).
- **Boundary data:** small Natural Earth extracts used only to draw the map in Figure 2.
- **Data audit note:** how the analysis file was verified and how GSI and LSI were generated.

## Quick start

```bash
pip install -r requirements.txt
./run_all.sh          # about 1–2 minutes
```

`run_all.sh` runs three scripts in turn:

1. `code/reanalysis.py` cleans and checks the data, estimates every model, and writes the tables, Figures 3–5 and `data/processed/`;
2. `code/fig1_conceptual_framework.py` draws Figure 1;
3. `code/fig2_study_location.py` draws Figure 2.

Running them on the files in `data/raw/` reproduces the files in `outputs/` exactly (checked file by file, with the package versions in `requirements.txt`). No network access is needed.

## Structure

```
data/raw/                 Input files, never modified (checksums in docs/DATA_AUDIT.md)
data/processed/           Cleaned analysis file written by reanalysis.py
data/external/            Natural Earth boundary extracts for Figure 2 (public domain; see SOURCE.json)
code/reanalysis.py        Estimation, tests, tables and Figures 3-5
code/fig1_conceptual_framework.py   Figure 1
code/fig2_study_location.py         Figure 2
code/prepare_naturalearth.py        Rebuilds data/external/ from Natural Earth (needs network; not part of run_all.sh)
outputs/                  Every table, figure and statistic (regenerated by run_all.sh)
docs/DATA_AUDIT.md        Data verification and construction of GSI and LSI
```

## Specification

- **Outcome:** circulation of the residential land use right (1 = circulated, decided or likely).
- **Principal measures:** GSI and LSI, which are field-administered three-level perceived-attitude ratings (1 = negative, 2 = neutral, 3 = positive) entered linearly as (x − 1)/2. These are not the computed headcount scores specified in the questionnaire; see `docs/DATA_AUDIT.md`.
- **Secondary measures:** D3 and D4, which are seven-point perceived-attitude items.
- **Estimator:** linear probability models with the full control vector (13 regressors) and case fixed effects. Standard errors are clustered by kampung (42 clusters), with t inference on 41 degrees of freedom.
- **Robustness:**
  - categorical coding;
  - winsorised controls;
  - probit average marginal effects with separation diagnostics;
  - bounded-coding checks on age and wealth.
- **Heterogeneity:** case-specific slopes with a restricted wild cluster bootstrap (Rademacher weights, 999 replications), plus East Malaysia interactions.
- **Spatial analysis (exploratory):** Moran's I with three-nearest-neighbour weights and permutation within cases.

The exact N is reported for every model. All use N = 369, except the exclusion of bounded observations (N = 313).

Figure 1 uses no data. Figure 2 places one marker per case at the mean of that case's six approximate kampung centroids, rounded to 0.01° (about 1 km), on Natural Earth boundaries. Kampung and household positions are not drawn. The other figures in `outputs/` (`fig3_…` to `fig6_…`) are diagnostic plots, not paper figures. `descriptives_by_case.csv` gives descriptive statistics by case.

Model codes in `all_estimates_long.csv` work as follows:

- **M1–M7:** linear probability models, as numbered in Table 3;
- **M1c–M3c:** categorical coding;
- **W1–W6:** winsorised controls;
- **P1–P6:** probit average marginal effects.

## Boundary data and licences

Figure 2 uses Natural Earth 1:10m admin-1 (Malaysian states) and 1:50m admin-0 (countries) boundaries, trimmed to South-East Asia and committed in `data/external/natural_earth/`. Natural Earth is in the public domain (https://www.naturalearthdata.com). The extracts come from the official GitHub mirror, pinned to commit `ca96624a56bd078437bca8184e78163e5039ad19`; `SOURCE.json` records the commit and the SHA-256 of each full download. `python code/prepare_naturalearth.py` rebuilds them.
